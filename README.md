# Advanced Naval Battle Simulator

## Module
SE1012 - Programming Methodology

## Assignment
Advanced Naval Battle Simulator

## Description
This project simulates a naval battle between a Battleship and multiple Escort Ships using C programming.

The project includes:
- Battlefield setup
- Projectile motion calculations
- Battleship movement
- Gun jam simulation
- Percentage damage system
- Battleship firing intervals
- Escort ship repeated firing
- Computer attack strategy
- Impact power degradation
- File handling and simulation result storage

## Source Files

- `part1a.c` - Basic battle simulation
- `part1b.c` - Battleship movement and gun jam simulation
- `part1c.c` - Percentage damage system
- `part2a.c` - Battleship firing interval and attack strategy
- `part2b.c` - Continuous escort ship firing
- `part2c.c` - Impact power degradation
- `battle_simulator.c` - Main simulator program
